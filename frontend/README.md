# PCA-100 frontend

This is the frontend workspace of PCA-100: a React 19 + Tailwind 4 + shadcn/ui
dashboard for the measurement UI.

## Commands

```
npm install
npm run dev        # Vite dev server, proxies /api to the backend
npm run build       # tsc -b && vite build
npm test            # vitest
npm run lint        # eslint
npm run typecheck   # tsc -b --force
npm run depcruise   # dependency-cruiser module boundary checks
```

See the root [README](../README.md) for how this fits into the full app, and
[CONTRIBUTING.md](../CONTRIBUTING.md) for the dev setup and quality gates.
